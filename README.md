# Coastal Peak Elite Services — Website

Landing page for **coastalpeakeliteservices.com**, hosted free on GitHub Pages.

## Edit the text
All text lives in **`site-config.js`**: headline, services, builder section, service area, phone, email, Instagram and Facebook.

To change something:
1. Open `site-config.js` in TextEdit and change the text between the quotes.
2. In GitHub, open this repository and go to **Add file → Upload files**.
3. Drag in the edited `site-config.js` and click **Commit changes**.

The site updates in 1–2 minutes.

## Files
| File | What it is |
|---|---|
| `site-config.js` | All text and contact info (edit this) |
| `index.html` | Page structure |
| `site.css` | Design |
| `site.js` | Menu, buttons and estimate form |
| `assets/` | Logo, icons and link-preview image |
| `CNAME` | Tells GitHub Pages to use coastalpeakeliteservices.com |

## Estimate form
The form opens the visitor's email app with a pre-written request addressed to your email. There is no monthly service to pay for.
